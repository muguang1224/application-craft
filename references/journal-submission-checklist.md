# Journal submission checklist

Run this against the target journal's **current** author guidelines (they change). This is a generic scaffold — always defer to the journal's own rules.

## Scope & venue
- [ ] The paper fits the journal's stated scope and article types.
- [ ] Format matches the article type (original research / review / short communication / case report).

## Manuscript structure
- [ ] Title page with all authors, affiliations, ORCIDs, corresponding author.
- [ ] Abstract within the word limit; structured (Background/Methods/Results/Conclusions) if required.
- [ ] Keywords as required.
- [ ] Section order matches guidelines (e.g. Intro / Methods / Results / Discussion).
- [ ] Word/page/figure/table limits respected.

## References & style
- [ ] Citation style matches the journal (numbered vs author-date; specific variant).
- [ ] All in-text citations resolve; no orphan references.
- [ ] DOIs included where required.
- [ ] Reference manager style file applied consistently.

## Figures & tables
- [ ] Resolution and file format meet requirements (e.g. ≥300 dpi TIFF/EPS).
- [ ] Each figure/table cited in order in the text; captions self-contained.
- [ ] Color/accessibility and size constraints met.

## Required statements (most journals now require these)
- [ ] **Data availability** statement.
- [ ] **Funding** statement (or explicit "none").
- [ ] **Competing interests** declaration.
- [ ] **Author contributions** (CRediT taxonomy if required).
- [ ] **Ethics approval / consent** (human or animal subjects) with approval numbers.
- [ ] **Acknowledgements**.
- [ ] Trial registration number if applicable.

## Submission package
- [ ] Cover letter to the editor (`templates/research-cover-letter.md`).
- [ ] Suggested reviewers + conflict notes, if required.
- [ ] Graphical abstract / highlights, if required.
- [ ] All files named per the journal's convention.

## Integrity
- [ ] Original, not under consideration elsewhere; all authors approved.
- [ ] Prior dissemination (preprint/conference) disclosed.
- [ ] **No similarity-score gaming.** Do not paraphrase to lower a 查重/Similarity report. Properly quote and cite. See `SKILL.md` → *Hard limits*.
